## Лабораторная работа №4. Основы JavaScript.

### Описание работы

Дополнена HTML-страница «О себе» из предыдущих лабораторных работ с помощью скрипта, написанного на JavaScript – **script.js**. Скрипт запрашивает имя пользователя, анализирует массив температур и выводит итоговую статистику.  

### Реализация

**prompt** – ввод имени пользователя.  
**alert** – вывод приветствия и статистики.  
**console.log** – вывод статистики в консоль.  
**findHottestDay(temps)** – функция, которая находит максимальную температуру в массиве.  
**filterWarmDays(temps)** – функция фильтрации, которая оставляет дни с температурой > 20 °C («тёплые дни»).  
**calculateAverageTemp(temps)** – функция, которая вычисляет среднюю температуру по всем дням.  
Также реализован отдельный цикл для нахождения *холодных дней* (≤ 10 °C), подсчёта их количества и вычисления их средней температуры.
